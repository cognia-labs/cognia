Tool approvals hold up under long and parallel runs: an answer to an ask that already ended only takes its card down (no session grant, standing rule or follow-up message), standing rules are written only after the runtime took the answer, an older turn's end no longer interrupts a newer turn's approval, and a card whose run is gone is probed again. On a paired phone, several asks queue instead of replacing each other, an answer clears only its own card, an interrupted ask shows as interrupted with Dismiss, and a card closes when its own call finishes rather than on any progress. A remote ask's timeout deny now waits for that ask alone, every waiting card hears about a Stop, and each turn's approval timeout applies.
