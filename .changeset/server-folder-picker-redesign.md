Choosing a folder on a paired server is easier and faster. The picker now shows one folder at a time with a clickable path above it: click a folder to go into it, and "Choose this folder" picks the folder you're in, which also works on touch screens. You can filter the folders, show or hide hidden ones, or type a path directly. Folders you have already opened come back instantly, even very large folders scroll smoothly, and a slow server reply can no longer show the wrong folder. When a folder can't be opened, the picker says why and offers to retry, go up, or jump to a folder the server allows. On a phone the allowed locations sit in a row above the list.
