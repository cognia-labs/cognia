Settings and sync are more reliable. A save no longer overwrites a value another device or window changed at the same time, the open settings page and the running appearance follow changes that arrive from sync, and a paired phone's change reaches the Host together with the save (a cleared value is cleared there too). The Host no longer answers a paired client's settings change with its own settings. Account sync: a device whose settings hold only defaults takes the account's settings when it joins, its own shared settings make the join ask first (after a backup), an interrupted first sync resumes, and changes made while a sync class is switched off stay on the device and are sent when it is switched back on, the newer change winning. A push failure stays visible after a successful pull, and a too-large row leaves the warning once it syncs. Settings files: an exported color preset imports again, values a key cannot hold are skipped and named instead of saved, and "Reset all to defaults" now clears every section's preferences, keeps search provider keys and other credentials, and leaves onboarding progress alone. The sync status badge says when a device is not paired or not synced yet, the settings search finds account sync and the recovery key, and a TURN entry typed into the STUN field is refused instead of being stored with its credential.
