Every Squad start now goes through one launch path. A workflow's "Run team" step passes its goal, shows its Squad run under the workflow run and stops it when the workflow stops. A scheduled run is recorded as the schedule's. Pause and Resume on the board reach a run on the paired Host. A refused pause, resume or stop from the command palette, `/squad` or a plugin now says why instead of passing silently. The ensemble, judge panel, council and Squad vote share one set of aggregation rules: a blank reply is a failed reply, answers are compared without surrounding whitespace, an attempt no judge scored can no longer win, and an invalid vote weight counts for nothing.
