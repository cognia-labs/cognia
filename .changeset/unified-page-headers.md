Every page header now follows one design. The first row always carries the page's icon, title, a one-line description and at most one status chip, with actions in a fixed order (count, refresh, up to two buttons, a "⋯" menu for the rest, and the main action last). View tabs, search and filters sit together in a second row in one shared style. Pages that drew their own tabs, search boxes or status pills now use the shared ones, and sub-pages show a back button where the icon would be.
