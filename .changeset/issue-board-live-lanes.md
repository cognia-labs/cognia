The issue board now stays current on its own, and the board honours the grouping and density chosen in Display.

- GitHub issues, shared-workspace issues and Agent Team or agent tasks appear and move on the board as soon as they change, without waiting for a local issue to be edited.
- Grouping by assignee, priority or project now draws swimlanes on the board, not only in the list. The My agents view opens grouped by agent. Dragging a card inside a lane changes its status only.
- Compact density now applies to board cards too.
- Reordering issues on the board now reaches a paired phone.
- On a phone, links that filter by project, cycle or assignee now open the filtered list, with chips to remove each filter. A link to a GitHub, shared or agent issue now says it can't be opened on that device. The status menu only offers moves the host will accept while an agent is working on the issue.
