Tool calls look and read the same everywhere: a subagent's calls, the simplified display mode and the run panel now use the main transcript's rows, with the full path, the HTTP status and the error under the row. An edit shows what changed (+2 −1) instead of how many edits it made, a read counts its lines the way an editor does, and a long error no longer squeezes the file or command it belongs to out of view.
