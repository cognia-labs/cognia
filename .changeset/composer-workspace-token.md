The bar above the home composer now starts with the workspace a new chat goes to ("workspace › folder · worktree"), so you can see and switch it right where you type. It opens the same list as the other workspace switchers, and switching in one place updates them all. In the web app, the sidebar no longer repeats the switcher above New chat. The folder now comes before the worktree, since a worktree is made from the folder.
