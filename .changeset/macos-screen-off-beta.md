Screen-off Computer Use comes to macOS as a beta (Developer ID build, macOS 14.4+, lid open): Cognia drives apps on one 1920×1080 virtual display while the physical screen sleeps, and Cognia's own window always stays on the physical screen. A screen-off capture or input never falls back to another screen, and an explicit monitor that no longer exists now fails instead of capturing the primary.
