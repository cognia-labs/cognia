Lark actions that run with a connected person's own authorization (docs, wiki, sheets, base, calendar, tasks, contact search) now work from chat only when the person who connected the account is the one asking; anyone else gets a refusal instead of borrowing that person's access. Lark calls also no longer switch to the app's own identity when personal authorization is missing or expired. Docs search and preview, Twin import, and Lark issue sync now ask you to reconnect the account instead.
