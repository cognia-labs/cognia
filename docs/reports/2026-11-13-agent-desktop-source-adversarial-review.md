# agent-desktop source adversarial review

Date: 2026-11-13. Scope: current uncommitted integration, focusing authority boundaries, stop/cleanup, and restart selection. The user authorized repairs and explicitly deferred verification. This report is source evidence, not compilation, test, native, installation, TCC, signing, or performance evidence.

Three bounded source-review tracks examined architecture, lifecycle, and restart/packaging. Changed functions received source follow-up. No external model CLI was invoked.

## Rejected or narrowed findings

- The Native raw AX gateway already had final mutation checkpoints. The missing-checkpoint finding was withdrawn after inspecting it.
- A fresh Host owner with repeated client tags does not revive an old Admission/token, which already compares Host identity. No lifetime tag blacklist was retained; pending epoch and lineage were the actual gaps.
- Engine configuration chooses the canonical application-session engine. Independent legacy granular Native APIs retain their explicit permission/fence/lease checks; treating them all as vendor-session actions would change the intended boundary.

## Remaining acceptance boundary

Only source inspection, editing, formatting, and generated command/message maintenance were performed. Tests, type checks, lint gates, builds, UI inspection, native fixtures, signing, TCC identity, crash timing and performance remain deferred. The private executable snapshot also needs native permission/signing acceptance.

Native remains the default; the candidate is opt-in Apple Silicon preview with no qualified release targets. Selection remains restart-only. While an old executor holds the inherited lease, new backend work is refused; after it exits, restart is the explicit recovery route. Settled means executor/held-input cleanup has finished, not that already accepted target-app transactions are frozen. Uninterruptible OS calls can keep a stop pending; that uncertainty is not reported as success.
