# 服务条款

生效日期：2026 年 11 月 22 日

本服务条款（以下简称“本条款”）适用于你对 Cognia 客户端软件（网页端、桌面端与移动端）以及 Cognia 可选官方托管服务（包括 `id.cognia.cn`、`sync.cognia.cn`、`signaling.cognia.cn` 与 `share.cognia.cn`）的访问与使用。使用 Cognia 或登录 Cognia 官方账号即表示你同意本条款。

## 1. 软件许可与本地优先模式

Cognia 客户端源代码依据 [Cognia 代码仓库](https://github.com/cognia-labs/cognia) 公布的开源许可证提供。你可以在不注册或登录任何官方云账号的情况下，离线使用 Cognia 或连接自托管基础设施。

## 2. 账户、密码与两类恢复密钥

Cognia 采用彼此独立的两层安全机制：

1. **本地档案保护**：你的本地档案密码与**本地保险库恢复密钥**用于保护保存在当前设备上的本地加密数据。Cognia 服务端从不接收你的本地密码或本地保险库恢复密钥，无法代你解锁已锁定的本机档案。
2. **可选云端账号与同步**：已关联的第三方登录方式用于验证你的云端身份；**同步恢复密钥**用于在手边没有已授权设备时添加新的同步设备。建议至少绑定一种备用登录方式，并妥善离线保管两类恢复密钥；在缺少密钥的情况下，Cognia 无法解密端到端加密的同步内容。

你需自行妥善保管自己的设备、密码、恢复密钥以及在应用内配置的第三方 API 密钥。

## 3. 第三方服务与 AI 模型提供方

Cognia 支持连接第三方身份提供方（如飞书、GitHub、Google、Apple）以及你自行配置的 AI 模型与工具服务。你对相关第三方服务的使用受其各自条款、计费规则及使用政策约束。AI 模型生成的内容可能不准确或不完整；在执行命令、应用代码修改或采纳自动化操作前，你应自行核实并承担相应责任。

## 4. 托管服务的合理使用

在使用 Cognia 官方托管的身份、同步、信令或分享服务时，你同意不会：

- 干扰、过载或绕过身份认证、速率限制、存储配额或安全控制机制；
- 尝试冒领、强行绑定或未授权访问属于他人的账号、设备或同步空间；
- 利用公开分享链接或同步存储传播违法内容、恶意软件或滥用流量。

为保障服务可用性、安全性或合规要求，我们可对异常或滥用请求采取限流、暂停或终止访问措施。

## 5. 账号注销与服务变更

- 你可以随时停止使用 Cognia，并可在 **设置 → 账户 → 身份** 中申请注销官方账号。冷静期届满后，你的云端身份与云端同步空间将被永久清除且无法恢复。
- 标有 **预览（Preview）** 的功能（如账号同步）可能随协议演进而调整。请定期通过 **设置 → 备份** 保存重要工作区数据的本地备份。

## 6. 免责声明与责任限制

在适用法律允许的最大范围内，Cognia 软件及其托管服务均按**“现状（AS IS）”**和**“可用状态（AS AVAILABLE）”**提供，不附带任何明示、默示或法定的担保（包括适销性、特定用途适用性及不侵权担保）。对于因遗忘本地密码或恢复密钥、第三方服务中断，或由用户配置的 AI 智能体执行的操作所导致的间接损失、附带损失或数据丢失，Cognia Labs 及其贡献者不承担赔偿责任。
