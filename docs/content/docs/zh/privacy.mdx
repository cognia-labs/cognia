# 隐私政策

生效日期：2026 年 11 月 22 日

Cognia 采用本地优先（Local-First）架构设计。你无需登录任何 Cognia 云端账号，即可完整使用网页端、桌面端（Tauri）和移动端（Capacitor）的核心本地功能。本页面说明哪些数据仅保存在你的设备上、在你自愿启用官方托管服务时我们会处理哪些数据，以及你如何管理或删除这些数据。

## 1. 保存在本设备上的本地数据

默认情况下，你的对话、智能体配置、技能、记忆、文件、设置以及第三方模型 API 密钥均保存在你自己的设备上：

- **浏览器端**：保存在按本地档案隔离的 IndexedDB 数据库及 Browser Vault（基于 `Web Crypto` PBKDF2 / AES-GCM 加密）中。
- **桌面端（Tauri）与移动端（Capacitor）**：保存在本地应用数据目录中，并由系统凭据存储或你设置的本地档案密码保护。
- **模型服务商调用**：你向自己配置的 AI 模型服务商（如 Anthropic、OpenAI 或自定义网关）发送的提示词、附件与工具输出，由你的运行环境直接发往对应服务商并适用其隐私政策；Cognia 身份与同步服务不会中转或保存你的模型 API 密钥。

## 2. 可选的 Cognia 官方账号（`id.cognia.cn`）

登录 Cognia 官方账号是可选功能。当你选择通过飞书、GitHub、Google 或 Apple 登录时：

- **身份信息记录**：官方 OIDC 服务仅保存内部账号标识（`usr_...`）、显示名称、头像链接（如有）、已验证邮箱（飞书登录使用不可路由的 `.invalid` 占位符，不将未验证邮箱用于跨渠道合并），以及各已关联登录方式的稳定外部主体标识（subject ID）。
- **不留存第三方 OAuth 令牌**：飞书、GitHub、Google 或 Apple 在登录或绑定时返回的访问令牌（access token）、刷新令牌（refresh token）和 ID 令牌在写入数据库前均会被剥离清空。Cognia 只确认“你是谁”，不会保留访问你第三方账号的权限。
- **令牌与安全限流**：Cloudflare D1 中仅保存短期授权状态、Cognia 自身的会话与刷新令牌以及接口限流计数，用于完成多端认证和防范滥用。

## 3. 可选的端到端加密同步（`sync.cognia.cn`）

当你在已登录的本地档案上启用“账号同步”时：

- **端到端加密**：同步内容（对话、角色、技能、记忆及共享偏好）与设备名称在离开你的设备前即已完成本地加密。同步服务仅保存带签名的设备注册表、密封的周期密钥信封（epoch-key envelopes）、设备加入请求以及加密后的操作日志批次。
- **永不同步的数据**：第三方模型 API 密钥、本地保险库密码以及设备专属设置始终只保存在各自设备上。
- **服务端可见范围**：同步服务仅校验设备签名并执行存储配额控制，无法获取你的明文同步密钥、同步恢复密钥或任何对话明文。

## 4. 其他可选托管服务

- **零知识公开分享（`share.cognia.cn`）**：当你主动创建公开分享链接时，分享服务只保存加密密文，解密密钥仅存在于浏览器不会发送给服务端的 URL 片段（`#k=...`）中。
- **配对信令（`signaling.cognia.cn`）**：仅在你配对自有设备时短暂转发建连信令，配对端点之间的通信负载保持端到端认证与加密。
- **组织自托管部署**：若你将 Cognia 连接到所在组织自行部署的网关，该部署下的登录与协作数据由你所在组织的管理员及策略管理。

## 5. 账号注销与数据清除

你可以随时在应用内的 **设置 → 账户 → 身份 → 注销账号** 中发起官方账号注销：

- **二次确认与冷静期**：发起注销需要重新登录确认，并进入服务端配置的冷静期（默认 7 天）。冷静期内你可以随时登录并撤销注销。
- **永久清除**：冷静期结束后，定时任务会先清除你的云端同步空间（删除全部加密同步数据、密钥信封、设备列表及操作日志，并写入不可逆的已清除标记以阻止残留短期令牌重建空间），随后删除你的全部会话、令牌、授权记录、已关联登录方式及用户记录。
- **本地数据独立保留**：注销云端账号不会删除当前设备上的本地对话与文件。如需清除本机数据，请在 **账户 → 危险区** 删除本地档案，或清理应用存储。
