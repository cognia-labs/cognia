## Problem frame

A Host-held run determines authority. Personal marks cannot unlock shell, arbitrary fetch, browser, plugin or third-party MCP channels. Registry-native tools, explicitly declared Host ports and plugin tools retain distinct ownership. Admission waits for other in-flight work before releasing private content.
