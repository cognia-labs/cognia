## Original request

> 帮我分析一下现在的权限管理和空间管理，看看差什么功能，或者存在什么问题，并且对照业内的优秀实践

> 进行一次对抗性审查，然后列出完整的问题列表

## 结论

**优先修数据丢失与授权边界。** 确认把会话移动到目标空间后，永久删除源工作区可清除该会话的旧消息。配对端已接收删除的工作区仍可留在内存中，重启后可留下失效的活动指针。邀请、服务端动作范围及 Host 撤销补查也发现独立缺口。

2026-11-20 对抗性复审基于当前工作树，HEAD 为 `3a49486dd126e390d1dc2ae3b9866de6281a68af`。两个独立上下文分别核对本地工作区与组织治理，再由主会话逐项复核。工作区链路运行 8 项合成探针，覆盖 7 个发现。线上与真实配对结果尚未验证。同模型复核已完成，按用户选择跳过额外跨模型复核。

## 完整问题清单

优先级按影响和处理顺序排列。P1 覆盖数据丢失、授权边界不一致、不可逆操作和现有核心流程无法完成。P2 覆盖收敛、可诊断性和常规管理效率。P3 为依赖产品或企业需求的缺口。表中「复现」指本地合成数据测试直接观察到的行为，「源码」指调用链上的事实或风险。

### 反证与结论修正

- 首轮把 ADR-0245 的按空间限制设备误写成现有功能。代码仍走 Owner 注册和按设备能力授权，已修正为 F15。
- 首轮「组织共享空间缺入口」的范围进一步收窄。企业协作 API 可以列出空间，飞书 Workbench 能选择。F01 是自助写入缺口，F30 是通用工作区的发现缺口。
- F02 的重新打开即恢复有产品测试。问题是归档对后台动作的含义和反馈。现有探针证明调度归属解析可达，还需要真实运行验收。
- 组织管理员跨空间管理、组织层停用由部署运维负责、降级角色后已有部分运行继续，均有 ADR 契约。F38 针对已被移除空间访问时的补查。
- `org-governance` 明确是展示型 rollout。旧成员 API 仍按权限处理。暂时缺少新版组织管理入口，沿用 F04。 [实施契约](../../crates/cognia-collab-server/ENFORCEMENT.md#L86)
- 历史遗留的三项 Rust 契约测试失败可重现。校验读取旧 TS 文件路径，实际定义已迁入 plugin-contract。归为验证设施缺陷，不计入产品清单。

## 推进顺序

1. **先修不可逆数据问题和授权契约。** F10 先覆盖历史会话归属。F03、F27 一起确立删除的可恢复写入边界。F22、F23、F38 优先核对授权范围、角色和撤销补查。共享邀请的 F20、F21、F39 适合一起修复和回归。
2. **再把空间管理路径接通。** 配对端以 Host 为权威，先解决 F11、F13、F14。团队按 F18、F19 补邀请闭环，再做 F01、F30、F04 的共享空间管理、发现和组织人员目录。
3. **改善治理效率。** 审计的准确性和检索，定向/限期访问，最后按企业需求推进角色与身份系统接入。

## Problem frame

G1 覆盖个人工作区、组织共享工作区，以及影响二者的目录信任、设备授权与 Agent 执行授权。本轮复审扩展到故障、迁移、配对收敛、邀请兑换、授权作用域及撤销兜底。以普通管理动作能否从入口完成、状态何时生效、故障后是否一致为核对点。空间指 Cognia Workspace。审计为只读，探针只使用临时合成数据。

### 复现与反证记录

- **归档与失败反馈**。使用合成项目归档，待 Dexie 落盘后由调度归属解析拿回原空间；重新打开同目录恢复。另令项目行写入失败，检查内存已归档而数据库未变化。
- **部分迁移与文件夹**。让定时任务重绑抛错，源空间仍在，对话已去 Default；分别用保留和永久删除两种模式确认工作区文件夹在源区消失后仍保留。
- **同步收敛**。外部删除项目行后调用客户端合并，得到旧项目仍在内存；模拟重新 hydration 时项目消失但活动指针保留旧 ID。迁移到 Default 后保留原会话 `updatedAt`，增量过滤的调用链见 F14。
- **对话历史**。通过实际本地会话移动入口把会话从 A 移至 B，确认消息还标 A。永久删除 A 后，B 中会话仍在、旧消息已不存在。全部数据为临时合成数据。
- **证据边界**。未测真实调度触发、日志平台和配对设备。授权相关问题依据现有源码契约判定，实际部署及用户的可见结果仍需验收。
- **既有 Rust 测试红灯**。`model::tests::{plan_enums_stay_in_step_with_the_client_unions,run_enums_stay_in_step_with_the_client_arrays,stays_in_step_with_the_client_status_and_priority_lists}` 仍在旧 TypeScript 转发文件查字面量。实际定义已迁入 plugin-contract。 [Rust 检查](../../crates/cognia-collab-server/src/model.rs#L537)、[TypeScript 转发](../../types/issues/index.ts)、[实际定义](../../packages/plugin-contract/src/types/issues/index.ts)
