## Problem frame

Make late plugin capabilities visible without declaring the first batch complete (O1, O2), and expose ACP steering only after negotiation (O3). Preserve authenticated host fetch and PII policy. Do not duplicate OpenCode runtime fixes in Cognia (C1).

## Reproduction and scope notes

- Source of upstream contract: https://github.com/anomalyco/opencode/blob/v2.2.7/CHANGELOG.md and tagged ACP agent/service/turn implementations.
- Native executable was the official npm @opencode/cli-darwin-arm64 2.2.7 binary. It and duplicate downloads were removed after verification to recover local disk space; safe logs and screenshots remain under .cache/opencode-2-2-7/.
- Existing scripts/smoke/opencode-v2-smoke.ts supplies the native test. The temporary package-smoke.ts uses the same procedure with a package entry injecting global fetch and the real PII gate; it does not validate the full app transport or service launcher.
- No external model or user credentials were used. Isolated runtime services, ACP process and test state were cleaned up.
- Root and sidecar lockfile changes preserve pre-task entries and unrelated importers; only OpenCode client importers and required new package/effect snapshots were added. Frozen offline installs passed.
- No Git commit or push was requested or performed. Existing concurrent source changes were preserved, including earlier confinement edits in the chat controller and its co-located test.
