## Problem frame

用户需要知道当前工作树中哪些套餐能读取服务端权威额度、能读哪些窗口，以及哪些账户会显示空值或误导性的读数。范围是 AI 编程订阅、套餐 API 和项目已接入的相关工具。充值余额、API RPM/TPM、Cognia 本地用量估算和 Gateway 组织配额分别有独立口径。市场对照选取国内外常见套餐和已有推理入口的服务，无市场份额排序。

1. **F1 火山方舟识别错套餐或漏套餐。** 查询只带 region 与 AK/SK，`GetAFPUsage` 有数据就提前返回。Renderer 丢掉套餐名，两种返回在相同窗口值下得到相同快照。缺少 AK/SK、服务端 soft error、未知格式和没有订阅均可落到空面板。Coding Plan 已识别窗口但缺少百分比字段时 Rust 默认 `0.0`，这一点为源码证据。 [Rust 源](../../src-tauri/src/subscription/volcengine.rs#L355) · [TS 源](../../lib/subscription/limits/sources/volcengine.ts)
2. **F2 Kimi 漏短窗与周窗，旧标签可能误导。** 比例字段样例返回 null，混合旧字段样例只展示旧计数。旧 relay 把这条计数固定标为 session 且 ISO 重置丢失。月总额度和 Extra Usage 钱包还有单独的官方 CLI Server 读取路径。 [描述符目录](../../lib/subscription/limits/descriptor/catalog.ts) · [Kimi CLI Server](https://www.kimi.com/code/docs/en/kimi-code-cli/reference/server-api.html#_get-api-v1-oauth-usage)
3. **F3 Codex 不同入口显示范围有差异。** 订阅页 WHAM 将返回 `limit_window_seconds=604800` 的主窗标成 session，附加限额和 credit 丢失。App Server 路径已按 limit ID 处理多个桶，桌面 Agent 状态卡只消费 primary。 [WHAM](../../lib/subscription/limits/sources/codex.ts#L188) · [TUI](../../cli/src/tui/runtime/limits-data.ts#L115) · [状态卡](../../components/settings/agent/codex-app-server-status-card.tsx#L206)
4. **F4 MiniMax 额外权益会被丢弃。** 当前插件对 `general` 的两个百分比做翻转，未消费官方客户端类型中的 status、count 或 `weekly_boost_permille`。这些字段存在但百分比缺失时没有该窗口的仪表。 [插件](../../plugins/minimax-subscription/plugin.json) · [MiniMax 官方类型](https://github.com/MiniMax-AI/cli/blob/main/src/types/api.ts#L1830)
5. **F5 Copilot 仍查旧 premium requests。** 自定义模板可保存但无法解读官方 `usageItems` 样例。组织预算与个人已用量需要明确凭证主体和权限。 [模板](../../lib/subscription/limits/custom/presets.ts#L114) · [GitHub 报告](https://docs.github.com/en/rest/billing/usage?apiVersion=2026-03-10)
6. **F6 ZenMux 手动入口缺默认请求路径。** 填 `https://zenmux.ai` 时模板会请求 `/`。设置正式路径及管理 Key 后，样例可显示 5 小时和周，省略月上限与重置次数。CCSwitch import 能保留原有完整请求路径。 [模板](../../lib/subscription/limits/custom/presets.ts#L235) · [导入](../../lib/ccswitch/import.ts#L110) · [ZenMux API](https://zenmux.ai/docs/api/platform/subscription-detail.html)
7. **F7 条件不明会显示 0/100 或空白。** `quotaOf` 把只有 `remaining` 的余额投影成 `used=0, limit=100, unit=percent`。TUI `nodeAuthedGet` 在 HTTP 401 时仍返回 body，解析后可以落成无数据，Connect POST 保留 status。桌面描述符收到合法 JSON 但无匹配可读字段也返回 null。 [诊断投影](../../lib/ai/operations/handlers/account.ts#L149) · [TUI GET](../../cli/src/tui/runtime/limits-data.ts#L361) · [描述符](../../lib/subscription/limits/descriptor/engine.ts#L200)
8. **F8 能力提示和调用端覆盖不一致。** 桌面逐账号启用查询，Glance 只预判 Claude OAuth 与 Codex ChatGPT 账号可查，其他套餐首次读数前不享受同样提示。聊天 `/usage` 走 Anthropic 定向实现。桌面插件账号由 vault runner 读取，CLI 和 Diagnostics 各自构造上下文。Web/Capacitor 没有等价的本机 vault 读数入口。 [查询策略](../../lib/subscription/limits/policy.ts) · [Glance](../../hooks/glance/use-glance-quota.ts#L54) · [聊天命令](../../lib/slash-commands/actions/billing.ts#L55) · [订阅初始化](../../lib/subscription/core/init.ts)
