## Problem frame

Assess whether current tests protect their stated behavior (G1), separating weak assertions, missing contracts, and execution-policy gaps (H1–H3). A successful audit provides reproducible current examples, a useful control, and a prioritized gap ledger. It does not estimate a repository-wide ineffective-test percentage from a targeted sample. Historical evidence is retained separately; this dated ledger is needed because the old audit is a snapshot JSON/report rather than an open ledger in the current skill format.

## Why tests can be green while behavior is unprotected
