## Problem frame

Two problems, one shared layer. G1: a managed acquisition can hang without a
bound (O3, O4), fail without saying why (O7), cost time no one can see (O5,
O6), and write a full tree before narrowing it (O1, O2). G2: a multi-root
bundle breaks relative layout (O9), provisions every root from the primary's
file (O10), integrates across repositories without honouring dependencies
(O11, O12), and several execution entries see one root (O14-O17). Done means:
every acquisition has a deadline, a cancel and a class; per-phase timings
exist; sparse tasks stop paying for the full tree (measured, M1); a Squad run
in which the SDK owes changes holds its consumer (M2); and `file:../sdk`
resolves in a managed bundle (M3). Out of frame: CDN seeds or disk snapshots
for remote cold clones (later, if M4 shows a need), Process Compose, West,
remote and sandbox multi-root supply (labelled "primary root only"), and
Markone's `cat-file` checkout, TOS archive, NAS cache, and dropping
`--no-hardlinks` (D4).
