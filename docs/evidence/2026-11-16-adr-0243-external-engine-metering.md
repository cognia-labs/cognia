## What the code did before

Read from the source at `077dc74ae8` (static reading by an exploration agent, then checked by hand where it mattered):

| Finding                                                                                                                                                                                                                               | Consequence                                                                            |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------- |
| The streaming wrapper settled only on `usage_update.tokenUsage`, which in practice only Devin-style ACP sends. Codex, Pi, OMP, OpenCode v1/v2, OpenClaude and DSH put usage on `done` / `message_end`.                                | A streamed turn on those engines was charged its whole hold.                           |

| `externalMeteredUsage` dropped a report with no token split, even with a USD cost (Goose reports only that).                                                                                                                          | Cost-only usage was lost.                                                              |
| The gateway's revoke returns a boolean; no Host command reads a ticket's metered spend (`spent_tokens` lives only in `crates/cognia-gateway/src/route_ticket.rs`).                                                                    | Exact gateway metering would need a Rust and wire-contract change; kept as a residual. |

## Decisions (the person's, 2026-11-16)

| #   | Question                                                       | Answer                                                                                                                        |
| --- | -------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| E1  | A gateway-capable engine without a Cognia model under a budget | Keep supporting its own login (not forced onto the gateway; not silently re-bound)                                            |
| E2  | Token-only budgets for subscription logins                     | Only a dollar ceiling needs Host pricing; token ceilings meter on the native lane as reported                                 |
| E3  | Stop proof on the native lane                                  | A successful turn end; failed, cancelled or lost turns are charged the whole hold. On the gateway lane, also a revoked ticket |

ADR-0243's layered-metering paragraph is amended accordingly (both languages).

## Residuals

- A gateway task settles on the usage its engine reports, bounded by the ticket; exact Host metering needs the gateway to return a ticket's spend (Rust + companion contract change).
- On its own login, an engine's model calls after a successful `done` (background agents) are not counted (decision E3).
- Adapters that report per message (OpenCode v1) can lag mid-turn until `done`, so the mid-turn stop can come late; the settlement uses `done`.
- ACP is declared `turn` for every ACP agent, but an individual ACP agent may send no usage; such a turn then has no usage and is charged its whole hold.
- No Tauri, paired-Host or real-provider run was made.
