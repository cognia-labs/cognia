## Problem frame

沿普通聊天 Agent Mode 的入口，核对工具选入、调用、取消、结果回放与最终状态。长任务范围覆盖一个模型轮次里的多步循环、跨轮 `/goal`、前台切换、关闭应用和 Host 重启。内置 Explore/Plan 用于补充已有纵深和压力证据。Squad、外部 Codex/OpenCode 和连接器自身的交付逻辑由关联审计负责，本文仅引用它们与内置执行路径交汇的控制边界。

## 当前表现

- **工具面和 Host 循环已有基础。** 两种 sidecar 都投影工具目录、审批与结果。AI SDK Host 还有按需 ToolSearch、逐段循环、上下文压缩、重复调用拦截和累计用量。standalone 可执行 renderer 工具，已补上 schema 校验、名称映射、调用身份、错误和取消。当前已有按 tool call ID 保留结果的逻辑，也已有 Stop/终态传播到 renderer 工具的桥接。[Host 循环](../../sidecar/src/runtimes/ai-sdk/index.ts#L596) · [ToolSearch](../../sidecar/src/runtimes/ai-sdk/index.ts#L520) · [standalone 工具](../../lib/ai/chat/standalone-tools.ts#L411) · [结果合并](../../lib/chat/sdk-message-adapter.ts#L80) · [取消桥](../../lib/claude/plugin-tool-dispatch-bridge.ts#L49)
- **长任务已有目标、保留上下文和部分验收能力。** Explore/Plan 有结构化进度压缩。达到 Host 安全上限会保留部分结果并给出提示。`/goal` 支持子目标、judge、节奏、预算、可选 Workflow 验证和人工验收。Host 有常驻后台 job 及完成通知机制。每一层保留的信息不同，进度摘要用于后续推理，执行回执用于决定动作是否可接续或重试。[压缩](../../sidecar/src/runtimes/ai-sdk/compaction.ts#L790) · [预算提示](../../sidecar/src/runtimes/ai-sdk/index.ts#L1826) · [Goal 验证](../../lib/goal/verification.ts#L171) · [ADR-0249](../content/docs/en/adr/0249-a-background-jobs-completion-reaches-the-agent.md)
- **历史实测有纵深，也出现过高压力不收敛。** 2026-10-21 CLI/sidecar + DeepSeek 的 25 文档链，Explore 和 Plan 各做 26 次模型请求、25 次按序文件读取且自然结束，单次约 74.6 秒和 42.9 秒。另一组历史代理压力实验用了测试流修正，Plan 在 20 分钟边界中断，当时主请求与摘要请求各 29 次、仅发布 3 个 checkpoint。本轮 22 步 Host 测试为注入流控制。以上样本适合定义重测场景。[历史实测及限制](2026-10-21-builtin-agent-budgets.md#continuous-completion-timing-follow-up-2026-10-21) · [22 步离线控制](../../sidecar/src/runtimes/ai-sdk/index.test.ts#L4014)

## 对抗复审结论

截至 2026-11-18，HEAD `f6b7354c51` 的共享工作树。复审重新跑首轮反例，独立核对 desktop、paired Host、standalone 与 headless 的消费者。下表是当前优先级口径。**已复现**表示实际生产函数、hook 或 SDK 在受控环境出现行为。**源码确认**表示正常入口和相关分支已追到，跨边界行为仍待验。**待验证**用于条件与风险尚需注入证明的事项。

- **误报完成的确会推进工作。** 桌面夹具使用真实 event handler 与 Plan driver，三种未完成输入均将步骤与单步 Plan 设为完成。Goal 路径另有 judge 或 verifier。Headless 返回带 subtype 的部分输出属于接口约定，风险在于有些消费者没有检查 subtype。独立配对 Host listener 对明确的晚到错误给出 failed，对 clean end 附带限额结果给出 completed。
- **续聊、重连和断点续跑是不同承诺。** 活 Host 的流可以重连，聊天历史可作为下一轮上下文，Plan 有人工 retry/skip/mark-done，Goal verifier 有部分持久恢复。普通聊天缺少继续同一 in-flight 尝试的入口。Host 重启的可选策略重投原消息，属于新的执行尝试。
- **审批竞态影响授权记录和控制状态。** 本地夹具证明旧答复会留下会话授权或待跟进指令，旧 event 可影响新请求。Sidecar 按会话和 request ID 关联实际等待项，过期 ID 不会命中已移除等待。旧答复执行了另一项工具、已有真实重复外部效果、生产竞态发生率，均待真实环境验证。
