## Problem frame

Repair detection parity, shared-key ownership, dependency review and execution. Keep incumbent contributions by default. Disable only named competitors through owned lifecycle pause leases; restore still-owned decisions on failure and preserve newer user intent. Dependencies use a registry client and the same consent/configuration flow. Runtime-only resources remain explicit registration metadata; no fictional manifest fields or automatic rename/rebind promises.
