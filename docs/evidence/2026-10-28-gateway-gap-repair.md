## Independent integration review (2026-10-29)

The fresh PII, wiring, static-export, Tauri/Rust, i18n and test-gap reviewers found concrete cross-feature defects beyond the first implementation. The following repairs have exact behavioral or deterministic evidence in V3-V8; final person event policy remains V9:

- Post-mask provider plugins could reintroduce media/rerank PII: RED returned 200; GREEN now returns 400 with zero upstream sends for prompt, query and documents. Plugin-added inspectable text is also gated when masking is off; unchanged ordinary-key input retains its prior policy.
- Bridge output validation preceded known paid usage settlement: settlement now precedes validation; unknown dispatched bridge usage conservatively retains the bounded estimate against ticket/key ceilings. Known unsent work releases its hold.
- Terminal SSE/NDJSON placeholders, mixed line endings and interleaved tool/block identities needed separate regressions; the restorer now buffers original frames, retains sequence/tool/block identity, and never synthesizes terminal frames or duplicates usage.
- Real WritesBrainBridge had a 10-second inner timeout: exact search/vision commands now receive a 130-second bound; actual socket tests passed 14/14 after reproducing failure beyond 10 seconds.
- Native child leases need stable source-provider concurrency/telemetry identity and a trusted member log audience without copying organizational billing authority.
- Frozen role vision capability checks and helper account-pool expansion now resolve accepted ticket/snapshot authority.
- Vendor +json bodies now take the same privacy/middleware boundary as application/json.
- Desktop nativeLease fetch needs the existing native proxy because production CSP and listener Origin checks reject WebView loopback fetch; no policy relaxation is authorized.
- Headless must install the existing gateway event/ledger/log consumer through the authenticated CompanionTransport, retaining exactly one desktop owner.
- One Host bridge alias shared by search and vision must be deduplicated before frozen task-plan compilation.
- Client configuration compare-and-write captured the wrong timestamp after content validation; it now retains one validated metadata/content snapshot for publication and rollback. Live key revocation precedes persistence, pending revocations block listener startup on recovery failure, and filesystem coordination runs off async workers.
- Native nullable bridge selector serialization prevented unrelated config edits; native defaults now emit an empty object and the TS parser accepts legacy nullable selectors.
- Final source-to-runtime tracing found the required person telemetry runtime used a forbidden channel scope and operator-only status command. Native authenticated member policy and safe epoch validation are being repaired before final handoff.

Memory pressure was not used to skip required checks. ENOSPC interrupted verification; only exact caches generated by this task were removed, with absence verified. Existing project data, other tasks' caches, and user client configurations were preserved. Actual paid-provider/native-shell acceptance remains distinct from local HTTP/SDK/isolated-home evidence.
