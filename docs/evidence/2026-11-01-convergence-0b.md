## Problem frame

<!-- One paragraph: the problem we are choosing to solve now, the outcome that
would show it is solved, and what is explicitly out of frame. Cite IDs. -->

Phase 0 track 0b closes the concrete defects the convergence audit verified before any kernel work starts: effects that retry forever or vanish (B1 fusion outbox, B2 swallowed workflow registration and a TS/Rust cron split), a second write authority (B3 Direct plane), outbound jobs whose authorization standing is lost (B4), a gate too narrow to see brain-dormant effects (B6) and the host-parity gate it feeds (B5), the archive sweep reading UI state on the brain (B7), a tool description promising delivery that does not exist (B8), and red gates on dev (B9). Solved means each defect is pinned by a test that went red to green and the plan's §6 gates pass on this branch (G1). Out of frame: kernel extraction itself (phase 1), ADR-0249 delivery for Monitor, and gates that fail only on the shared tree.
