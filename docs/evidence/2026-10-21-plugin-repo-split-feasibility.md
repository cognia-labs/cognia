## Problem frame

Current frame (2026-10-25): assess whether first-party plugins can be maintained and released from their own repository (G8), using current checkout evidence rather than treating the 2026-10-21 findings as current. Compare a plugins-only extraction with extracting plugins plus SDK, and distinguish source independence, artifact consumption, runtime boot, feature delivery and release independence. This round is research only (C1). Earlier implementation decisions and evidence below are historical; they are not authorization to move or publish code in this round.
